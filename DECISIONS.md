# Decisions — smells

| # | Decision |
|---|---|
| 1 | Maintain the reusable code-smell scanner in a separate Git repository called `smells`, outside consuming projects. Rust remains the first/deepest pack; Python and TypeScript use separately validated versioned packs behind the same CLI/report seam. |
| 2 | Provide a standalone development executable using `src/main.rs`. Projects invoke it through a hook or quality runner and supply checked-in policies; scanner code has no application production dependencies or hard-coded project identities. |
| 3 | Deterministic verdicts use fixed pattern measurements, explicit versioned policy and pinned captured inputs. Required missing checks fail. Reports include function/type values below limits and explicit coverage statuses for all 23 Refactoring.Guru smells. Exact exceptions remain pending and nonempty exception input is rejected. |
| 4 | Keep OSV, Gitleaks, application tests, coverage generation, and hook composition with each project's broader quality runner. Preserve existing hooks; the provided hook is an inactive example until implementation and staged-snapshot fixtures pass. |
| 5 | Publish this standalone repository as public `mindful-time/smells` so GitHub can enforce pull-request-only `main` governance on the current plan and consumers can pin tested scanner releases. Public visibility does not grant write access or create an open-source license; hook integration must continue to fail when a required executable is unavailable. |
| 6 | Implement source-pattern detection before automated refactoring. rust-v1 inventories 28 rules, with 17 source detectors implemented and 11 compiler/type/contract/history detectors pending. Structural matching is deterministic but is not proof of semantic design defects or of the absence of every smell. |
| 7 | The first source scope is authored_all_cfg, including tests and inactive branches. It is not the earlier proposed active-production compiler scope. Policies explicitly adopt this scope; unsupported scope is an error. Duplication uses the documented normalized 4-token multiset algorithm; function lines use lexical source spans, independently of Clippy/cargo-crap conventions. |
| 8 | A policy selects exactly one language pack. `--path` and `--staged` are shared across languages; staged selection comes from the staged policy blob. Mixed-language repositories run one explicit policy per language rather than introducing an implicit auto-detection policy. |
| 9 | Python and TypeScript use pinned Tree-sitter grammars and `authored_source`. A Rust class-equivalent owner is a `struct`/`enum` plus every resolved `impl`; Python and TypeScript use actual class syntax. Portable source packs implement ten rules and expose the remaining semantic/provider rules as pending instead of guessing. |
| 10 | Worktree traversal never follows symlinks. A symlink whose path has the selected pack's source extension is rejected as a source-substitution attempt; a non-source symlink is skipped because it cannot enter that language corpus. Example policies share common monorepo cache/build exclusions so generated cross-stack source is not treated as authored input. |
| 11 | Portable duplicate detection remains exact while scaling through multiset-Jaccard prefix filtering: discard below-minimum bodies, impossible size ratios, nonshared globally ordered prefixes, and impossible positional overlap before charging `maximum_pairs` for a full similarity comparison. For a pinned Tree-sitter gap, TypeScript performs one narrow position-preserving reparse of generic call type arguments shaped exactly as `typeof import("literal")`; any remaining syntax error still fails closed. |
| 12 | Reports lead with exactly one deterministic result for each of the 23 canonical smell patterns. Rule evaluations remain the evidence layer: smell results aggregate blocking/review counts and rule readiness, then reference exact matched finding indexes. Checked-no-match is scoped to executed measurements and never claims semantic absence. |
| 13 | Monorepo reports group smell results by repository implementation before presenting the repository rollup. The nearest ancestor `Cargo.toml`, `pyproject.toml`, or `package.json` owns a source file across languages; nested manifests win, same-directory manifests combine, and sources without a manifest remain explicit as `__unowned__`. Path and staged capture use their respective manifest snapshots, reject manifest symlinks, and keep every location repository-relative. |
| 14 | This scanner repository dogfoods its executable through one fail-closed `pre-commit-push` target shared by checked-in pre-commit and pre-push hooks. The gate performs locked compilation, Clippy, tests, a self-smell scan, two-tier CRAP analysis, Gitleaks, and an OSV scan of `Cargo.lock`. CRAP's required target is 5: every higher score is exposed to the agent with exact evidence. Its absolute hard limit is 10: any higher score blocks the hook without a baseline exception. Installation refuses to replace an existing hook path or hook file. Consuming projects still own their broader quality runners. |
| 15 | GitHub Release archives are the primary language-neutral distribution. The release matrix builds five host targets and Maturin binary wheels from one pinned Rust source commit. No sdist is published, so Python installation cannot silently fall back to local Rust compilation. |
| 16 | Releases are manually dispatched from `main` with an exact stable `vMAJOR.MINOR.PATCH` input. The workflow reruns the full gate, builds and natively smoke-tests all five targets, generates checksums plus dependency and artifact SBOMs, and only then creates the tag and immutable release. GitHub signs an attestation over the release, tag, commit, and assets. PyPI publication and native macOS/Windows publisher signing remain separate explicit decisions. |
| 17 | `main` is PR-only with no administrator bypass and `mindful-time` as the only writer; required CI rejects pull requests whose head repository is not a fork. Public visibility enables GitHub branch protection on the current plan. Release dispatch is independently restricted to the repository owner. |
| 18 | Supersede only the no-license clause of Decision 5: beginning with version 0.2.1, Smells is licensed under the OSI-approved MIT License, with `mindful-time` as the copyright holder. Cargo metadata, Python wheel metadata, source, and standalone release archives must identify or include the same canonical root `LICENSE`. |
